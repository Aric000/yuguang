# 社区浏览（Mac）

从窗口右上角切换按钮进入「社区板块 → NBA → 篮球资讯 / 主队专区」，也可进入步行街、足球、CBA 等公开板块。关注球队会出现在「我的主队」。不需要离开精简窗口。

- 设置 N 行时，列表显示 N 条帖子，另有 32pt 工具栏。右键也能更改条数。
- 最新发布使用公开页面的 `-postdate` 排序。每次最多 50 条，滚动到底按页追加，帖子 ID 去重；每次浏览最多缓存 1000 条。
- 「回复最多 · 已加载」对已获取的帖子排序。新增页面后重新排序，按帖子身份保留滚动锚点；不声称是整个板块的历史回复榜。
- 点击帖子显示正文和公开评论。精简阅读默认纯文字，右键可启用图片；展开后显示原文图片。左上返回列表，保留列表位置。成功读取的帖子置灰，最近 2000 条已读 ID 保存在本机。
- 设置「我的主队」支持多选 NBA 球队，与直播收藏、切换菜单共用并保存。篮球资讯默认「只看主队新闻」，可在工具栏切回全部。未选择主队时提示去设置。
- 主队资讯匹配标题与正文中的球队名及常用别名，不通过球员姓名推断球队。来源列表每页最多 50 条，正文每批筛选 12 条，最多并发 3 个请求，纯文本结果缓存 10 分钟（最多 512 篇）。没有匹配时可继续查找，读取失败的资讯不混入结果，筛选菜单显示暂无法识别的数量。
- 评论显示「亮了 N」，将官方高亮评论与普通评论按 ID 去重、按亮数降序；气泡菜单可继续加载更多评论，累计合并后重排。排序范围明确标记为已加载评论，未读取的普通评论不声称已参与全局排行。工具栏刷新从第一页重新读取。右键可在浏览器打开原帖。
- 精简模式离开鼠标后，背景与工具按钮透明；可拖动标题区域移动窗口。列表行点击优先。

## 数据来源与限制

读取 `https://bbs.hupu.com` 的公开网页 SSR 数据：板块页 `window.$$data.topic.threads`，详情页 `__NEXT_DATA__.props.pageProps.detail`。没有新增私有接口、账号登录或后端服务。翻页路径已用公开页面验证：`/lakers-postdate-2`、`/<tid>-2.html`。

这是页面适配而非稳定开放 API。遇到验证、删除、权限限制或结构变化，会显示错误并允许重试；不会用演示数据替代。动态列表在翻页期间可能有帖子移动，ID 去重防止重复，但无法保证一份固定时间的完整快照。第一版支持公开正文、图片、平铺评论；暂不提供登录、发帖、回复、视频播放或楼中楼展开。

文章内容在无持久 Cookie 的 WebKit 阅读器显示，禁用脚本并限制资源加载。窗口外观及列表使用原生 SwiftUI / AppKit，沿用系统字体。

## 本地修正

- 主队设置收起为一行摘要；「选择…」打开独立多选弹窗，支持搜索和清空。点击「完成」后统一保存，取消不改变主队。
- 列表按实际滚动位置判断是否接近底部，请求完成后重新检查，连续无匹配批次也能继续；底部「加载更多」可直接点击。查看详情、远离底部或遇到错误时停止自动追加。
