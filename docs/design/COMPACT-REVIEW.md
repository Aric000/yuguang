# B 定稿与多行精简模式

用户定稿 B「余光之眼」，移除应用内的候选选择，保留历史矢量稿。菜单栏始终展示单色 B，开启菜单栏比分时图标与比分并列。AppIcon 由与窗口相同的 BrandGeometry 原生绘制，未引入第三方素材。

精简模式右上角增加双向箭头，单击打开原生比赛菜单：当前日期、比赛状态与比分、当前比赛勾选、日期子菜单和刷新操作。切换调用现有选场 / 取消旧请求逻辑，不调用展开窗口；窗口的尺寸、位置和精简模式状态均保留。赛程菜单不受全窗口的球队筛选限制。

设置支持 1–6 行，总高度 32 × 行数 pt，含首行比分。1 行维持原布局，多行在下方展示最新解说与时间；显示不足时保留空间，不编造内容。按钮始终位于首行最右侧。鼠标离开时背景、阴影和按钮继续隐藏，多行文字保持可读。拖动区域避开首行最右侧两个按钮，下方整块仍可拖动。

已查看 single / multi / multi-transparent、正式 B 标题及设置页的原生截图。检查中确认首行右侧按钮不会盖住文本，文字溢出以省略号处理；设置项明确注明行数含比分行。

原生检查覆盖 B 模板菜单图标、3 行 96 pt、6 行 192 pt、修改行数保留上边缘、切换比赛保留形态与位置、跨球队筛选切换以及原有透明 / 隐藏 / 置顶行为。原生程序未声称通过网页 DOM inspector。

原生比赛按钮在弹出菜单期间保持背景与操作区可见，避免鼠标离开主窗口进入菜单时菜单被撤销。桌面交互已从菜单选中另一场比赛，并在原三行大小内更新比分，未展开窗口。

新增「启用简洁模式」独立持久化偏好：开启立即折叠，下次启动优先折叠；手动展开和进入设置保留偏好，开启期间窗口中的比赛区与赛程行也隐藏队徽。关闭恢复正常窗口。测试新增启用、临时展开保留偏好、关闭恢复三个检查。

最终 release 编译和 20 项原生检查通过。已查看 simple-window 原生截图，确认开启简洁偏好时完整窗口不显示队徽；三行和透明三行截图保持 96 pt 高度，操作区始终在首行右侧。已实际操作设置的 1–6 行选择，并从原生比赛菜单点选另一场，窗口保持三行而没有展开。
