# v0.3.0 发布前审查

审查范围：从 `1bafa51` 起的 Mac 社区浏览、多主队设置、原生弹窗、连续分页与评论高亮，以及发布文档和项目 skill。Windows 仅同步版本元数据，功能保持文字直播。

## 结论

经代码检查及下列验证，未发现阻断本次发布的问题。异步列表和详情请求具备取消与代际检查，分页按帖子 ID 去重；主队筛选每批 12 条、最多 3 并发，并限制缓存。评论高亮与普通评论合并去重后降序，隐藏评论保持隐藏。文章脚本禁用，资源由 CSP 限制；应用未引入账号或持久网页 Cookie。

发布前补齐了一个验证缺口：此前 CI 未执行社区状态诊断，现已把 `--check-forum-model` 加入普通构建与 Release 构建。README 和发布说明明确社区为 Mac 功能，排序范围为已加载数据。

- Mac 原生窗口：29 项检查通过，包括拖动、隐藏、快捷键、行数与顶边保持。
- 原生窗口实际连续滚动：1→2、2→3、3→4 页，累积 199 条；详情返回位置保持；主队独立弹窗与队徽入口已查看实际截图。
- 真实虎扑抽查：两页列表去重、正文与第二页评论可读，评论亮数降序；主队正文筛选可用。
- Windows：Mac 上运行 32 项核心检查通过。WPF 窗口、安装、卸载检查由 GitHub Windows runner 完成，不能用本机核心测试代替。

- 发布 skill 格式校验通过。附件校验脚本公开 API 实测遭遇限流，因此发布后需结合连接器读取真实构建及附件信息，不能将 API 失败写成成功。

## 范围与限制

公开 SSR 页面不是稳定的官方开放 API，可能遭遇验证或变更。主队按球队名匹配，无法承诺识别正文中未提球队的全部新闻。动态分页不能保证固定快照；回复和评论排序仅覆盖已加载记录。macOS 14 使用底部视图出现/消失回退，macOS 15+ 使用系统滚动几何事件；本机实际滚动验证覆盖后者。未声称完成多系统人工验收、完整安全审计或 Apple 公证。

最终发布是否成功，以 GitHub Release 工作流和安装包附件核验结果为准。
