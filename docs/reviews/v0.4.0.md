# v0.4.0 发布前审查

范围：相对 `6c3f21b` 的 Mac 精简模式统计、主队新闻快捷入口、主队弹窗入口，以及双端版本元数据与文档。Windows 仅同步版本号，不声明支持统计或社区新功能。

## 结论

经检查与以下验证，未发现阻断发布的问题。统计请求以比赛、球队与刷新编号驱动，离开视图或切换球队取消旧任务；响应和清理加载状态另以请求身份隔离，防止旧任务覆盖新任务。已结束比赛成功获取后停止刷新，失败保留已有内容并允许重试。缺失数值显示「—」，球员及球队 ID 支持无损整数字符串。

截图检查发现统计表头随列表滚走，已改为固定表头，球员列表垂直滚动、整表水平滚动。精简窗口至少保留三行统计内容和一行工具栏；回到直播恢复直播行数。切换菜单的当前项勾选已排除统计状态，避免同时勾选直播。

主队新闻复用原有板块和筛选逻辑，没有改变公开正文的执行策略。未选主队时直接打开原生多选弹窗；草稿、取消、完成统一保存行为保持。

## 实际验证

- Mac：20 项核心测试通过，编译启用 warnings-as-errors。
- 社区状态：25 项检查通过，包括连续无匹配批次、重复页去重和主队草稿保存。
- 原生窗口：31 项检查通过，包括快捷键、拖动、隐藏、精简高度、统计与直播切换。
- 真实统计：双方各读取 18 名球员，已查看浅色与深色原生截图；固定表头可见，返回三行直播窗口通过。
- 原生社区：实际连续滚动 1→2、2→3、3→4 页，共 197 条；详情返回位置保持；精简与展开模式主队弹窗已显示，并查看截图。
- Windows：本机 32 项核心检查通过；WPF 窗口、便携程序、安装和卸载由 Windows runner 执行。
- 本机 v0.4.0 DMG/ZIP 已打包，ad-hoc 签名核验通过。

## 边界

真实接口和公开网页是第三方数据源，可能延迟、限流或改变结构；联网统计捕获仅作本机验证，不作为 CI 的联网前提。截图不能代替所有系统版本、多显示器和完整人工验收。没有声称完成 Apple 公证或 Windows 代码签名。

GitHub Release 的完成状态以目标提交的双端 Build、Release 工作流与六个安装/校验附件核验结果为准。
