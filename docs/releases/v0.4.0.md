使用余光关注比赛，一边用 AI 编程，一边观看比赛。

## Mac：精简窗口查看比赛统计

- 先选择比赛，再点击 `⇄ → 数据统计`，直接在精简窗口查看球员上场时间、得分、篮板、助攻、抢断、盖帽和正负值。
- 球队菜单切换双方；固定表头，向下浏览球员，宽度不足时可横向滚动。
- 打开统计时每 15 秒刷新，已结束的比赛成功读取后停止轮询；支持手动刷新和失败重试。
- 统计至少显示三行内容及一行工具栏，右键可调整到 3–6 行；一键返回文字直播。

## Mac：更方便地切换主队新闻

- `⇄ → 主队新闻列表` 直接进入所选球队资讯。
- `⇄ → 更改我的主队…` 可在精简窗口打开多选弹窗。
- 新闻筛选菜单也支持更改主队；未设置主队时，点击提示直接选择。

## 下载与范围

本次统计和主队新闻快捷入口仅在 **macOS** 提供。Windows 继续提供原有 NBA 文字直播，同步版本号；Windows 原生窗口与安装包检查由 GitHub Actions 执行。

- macOS 14+ / Apple Silicon：DMG 或 ZIP。
- Windows 10/11 x64：setup.exe 安装版或 portable.exe 便携版，自带运行时。
- 安装包由 GitHub Actions 构建上传，附 SHA-256 校验文件。

虎扑数据可能延迟、不完整或调整结构。主队新闻按标题、正文中的球队名匹配；回复和评论排序仅覆盖已加载内容。Mac 使用 ad-hoc 签名，尚未 Apple 公证；Windows 未配置代码签名。
