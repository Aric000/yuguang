使用余光关注比赛，一边用 AI 编程，一边观看比赛。

## Mac：在精简窗口里逛社区

- `⇄ → 社区板块` 选择篮球资讯、主队专区、步行街等公开板块，保持精简窗口浏览。
- 列表按设置显示 1–6 条帖子，另有一行工具栏；向下连续加载、去重，支持最新发布、已加载帖子的回复数排序与刷新。
- 点击阅读正文和评论，返回保留位置；已读帖子置灰。精简阅读默认纯文字，可启用图片或展开阅读。
- 评论显示「亮了 N」，高亮与已加载评论合并去重、按亮数降序，加载更多后重排。

## 多个主队，一个入口

- 设置中的小队徽与 `＋` 打开独立弹窗，支持搜索、多选、清空，点「完成」统一保存。
- 篮球资讯默认只看主队，也可切换全部。资讯按标题与正文中的球队名匹配。

## 修复与工程

- 修复到底部后不能继续加载的问题，连续无匹配批次也能继续；保留可点击的「加载更多」。
- 新增项目发布 skill `$yuguang-release`：审查、测试、打包、提交、Release 与附件校验。
- CI 增加社区状态诊断。本机通过 18 项 Mac 核心测试、25 项社区状态检查、29 项原生窗口检查与 32 项 Windows 核心检查。

## 下载与边界

社区浏览与本次新设置目前仅在 **macOS** 提供。Windows 此版继续提供原有原生 NBA 文字直播，并同步版本号。

- macOS 14+ / Apple Silicon：DMG 或 ZIP。
- Windows 10/11 x64：setup.exe 安装版或 portable.exe 便携版，自带运行时。
- 安装包由 GitHub Actions 构建并上传，附 SHA-256 校验文件。

公开网页可能变更或需要验证，数据可能延迟；分页不是固定快照，排序覆盖已加载内容。Mac 使用 ad-hoc 签名、尚未 Apple 公证；Windows 未配置代码签名。
