# 余光 v0.5.0：Mac 新闻恢复与安全验证

Mac 新闻遇到虎扑安全验证时，过去只能显示加载失败；现在可以在余光内打开虎扑验证窗口，完成验证后继续阅读。新闻请求复用该窗口的本机会话，重启后也可复用尚未过期的会话。

- 列表、正文和更多评论均提供安全验证入口；验证窗口保持在悬浮窗口前方。
- 正文筛选遇到验证码时停止自动加载，保留待处理新闻，重试后继续筛选，避免把受拦截新闻误判为不匹配主队。
- 验证窗口运行虎扑网页脚本；普通文章阅读器仍禁用脚本。不会读取或导出其他浏览器的 Cookie。

本次新闻修复仅适用于 macOS。Windows 同步版本号并继续提供原有 NBA 文字直播功能。

提供 macOS 14+ Apple Silicon 的 DMG / ZIP，以及 Windows x64 安装版 / 便携版，附各平台 SHA-256 校验文件。Mac 为临时签名，尚未完成 Apple 公证；Windows 未配置代码签名。

虎扑为第三方数据源，是否放行及会话有效期由虎扑决定；本次修复不保证永久免验证。主队资讯按标题和正文中的球队名匹配，评论排序范围为已加载数据。
